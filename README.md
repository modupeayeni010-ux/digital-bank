# Digital Banking System

A backend API for a digital banking system built with Node.js, Express.js, MongoDB, and NIBSS API integration.

## Features

- Customer registration and login
- JWT authentication
- BVN customer onboarding and verification
- Bank account creation
- ₦15,000 initial account funding
- Account balance enquiry
- Account name enquiry
- Intra-bank transfers
- Inter-bank transfer integration
- Transaction history
- Transaction status checking
- Customer data protection

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Axios
- NIBSS API
- Postman
